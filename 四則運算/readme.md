# 🧮 四則運算練習器（港式直式・填空・字母謎題）

一個純前端、單一 HTML 檔案即可執行的香港小學四則運算工作紙產生器。無須安裝任何相依套件或後端伺服器，打開瀏覽器即可離線出題、互動對答案、檢視港式直式詳解與雙欄列印。

## ✨ 主要功能

- **橫式計算與項目填空**：支援 `0～20` 題自訂、加減乘除自由開關、乘除位數嚴格把關、單層括號、一位小數（可選出現次數），以及「答案不在最後」的反推填空題。
- **單／雙層重疊直式填空**：自動產生保證唯一解的直式填空，支援港式長除法（預設）與短除法即時切換；每題皆可進入「編輯題目」微調數字、字母與運算符，並即時驗算唯一解、多解或無解。
- **A/B/C 字母直式謎題**：手動輸入支援數位內挖空與重複字母（蟲食算），自動轉為直式並附下方聯動答欄，預設「不同字母代表不同數字」且可按需切換。
- **智能手動輸入與防呆**：內建手機友善的一鍵數學符號鍵盤列，支援冒號 `:` 作除號與行首題號自動清理，並對負數步驟及無解算式即時警告阻擋。
- **港式直式詳解與解題教學**：自動生成對齊小數點、進退位標記、高位乘法補零與長／短除法的直式步驟；直式填空於答案頁附「逐步解題教學」，滑過或點擊步驟可同步高亮對應格子。

## 🚀 快速開始

1. 下載本儲存庫中的 `arithmetic_practice_v7.html`。
2. 直接使用任何現代瀏覽器（Chrome、Safari、Firefox、Edge）雙擊開啟即可使用。
3. 調整上方工具列參數後按 **「🎲 出題」**，或展開 **「✍️ 手動輸入題目」** 自訂練習卷。

## ✍️ 手動輸入範例

每行一題，系統會自動分流為橫式題目或直式填空：

```text
(123 + 45) × 6
(? + 45) × 6 = 1008
1234:5
2□5 + 13□ = 378
AB + A = BCC
(AB + BA) × C = 297
```

## 🖨️ 列印與裝置支援

題目與答案詳解皆支援 A4 左右雙欄省紙排版，並內建「純淨列印預覽」與「下載獨立列印檔 (HTML)」功能，特別針對手機瀏覽器及 Firefox / Firefox Focus 優化，確保空白格不印出多餘問號。
