香港常用紙張及樂譜 PDF 生成器
這是一個以單一 HTML 檔案寫成、完全離線運作且無需任何外部套件的網頁工具，專為製作 1:1 實物毫米比例的向量列印紙張與樂譜而設。
主要功能
￼ 8 種實用格式：涵蓋單行紙、方格紙、香港中學繪圖紙（1mm／2mm 三級線條與可選坐標軸）、五線譜（支援單行、鋼琴大譜表、三行伴奏譜及純向量譜號／花括號）、模擬 DSE 中文作文紙（支援跨頁累計字數）、田／米字格、港式小學英文簿（等距紅藍藍紅循環及標準四線三格）以及點陣紙。
￼ 高度自訂版面：內置 12 款常用預設範本，可自由調整紙張尺寸（A4／A5／B5／F4／Letter）、直橫向、頁數、頁邊距、行距格距、線條顏色粗細、左邊單／雙紅線，以及可自由輸入及左右微調位置的頁頭。
￼ 雙重向量輸出：內建純 JavaScript 向量 PDF 1.4 生成器，一鍵即可下載銳利檔案；同時支援瀏覽器列印另存，並針對 iOS 及受限瀏覽器提供分享與帶設定網址匯出輔助。
使用方法
直接以瀏覽器（Chrome、Edge、Safari 等）開啟 https://ck-from-hk.github.io/Study/paper/⁠ 即可即時預覽及匯出。列印時請選擇「比例 100%／實際大小」及「無邊界」，即可獲得精準的毫米尺寸。
